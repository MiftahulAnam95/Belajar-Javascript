# JavaScript Beginner Lab

Website belajar JavaScript interaktif untuk pemula setelah HTML dan CSS dasar.

## Fitur

- 20 materi bertahap dengan contoh HTML, CSS, dan JavaScript.
- Setiap materi punya halaman sendiri di folder `materi/`.
- Quiz, recall challenge, debugging challenge, mini project, dan progress tracker.
- Editor tiga panel untuk mencoba HTML, CSS, dan JavaScript langsung di browser.
- Dark mode dan progress tersimpan di `localStorage`.
